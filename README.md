### Hoje

Opero em produção uma instância n8n com **346 workflows** — mais de **12 mil
execuções por dia**, **99,6% de taxa de sucesso**. Trabalho via API REST:
criação, diagnóstico de execução por ID e versionamento. Não pelo clique-e-arrasta.

Os fluxos que eu sustento movimentam cobrança, agendamento e atendimento de uma
operação real, todo dia, sem supervisão manual.

### O que eu integro

CRM · ERP (inclusive legado em SQL Server) · gateway de pagamento ·
plataformas de telemetria e rastreamento veicular · WhatsApp Business Cloud API ·
Google Workspace · APIs de LLM

OAuth2, Bearer, API key, header customizado. Paginação, rate limit, retry,
